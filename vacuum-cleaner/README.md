# Arduino-Based Vacuum Cleaner Robot

An autonomous 4WD robot car that moves around, avoids obstacles using an ultrasonic sensor on a servo motor, and vacuums dust using an integrated fan motor.

Developed for the Summer Training 2026 program at Mansoura University, Faculty of Engineering.

---

## Features

* **Autonomous Navigation:** Drives forward and continuously monitors clearance distances.
* **Obstacle Avoidance:** When blocked, reverses and sweeps left/right using a servo-mounted ultrasonic sensor to pick the clearer path.
* **Vacuum Action:** Suction fan runs continuously to collect dust while navigating.
